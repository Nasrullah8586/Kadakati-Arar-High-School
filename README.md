# Kadakati Arar High School — EduConnect

**EduConnect** is a modern school management and information website developed for **Kadakati Arar High School**.

## 🌐 Live Website

https://kadakati-arar-high-school.onrender.com/

## 📌 Project Overview

EduConnect provides a centralized digital platform for students, teachers, parents and school administration to access important school information and services.

## ✨ Key Features

* School Information & History
* Notice Management
* News & Events
* Dynamic Gallery
* Teacher Directory
* Teacher Profile Management
* Teacher Authentication
* Email Verification with OTP
* Password Reset
* Admin Dashboard
* Teacher Dashboard
* Dynamic School Content Management
* Google Maps Integration
* Responsive Design
* SEO & Google Search Console Integration

## 👥 User Roles

### Visitor

Visitors can explore school information, notices, news & events, gallery, teachers, history and contact information.

### Teacher

Teachers can securely log in, manage their own profile information, update their profile photo, manage social links and reset their password.

### Admin

Administrators can register, update and delete teachers and manage notices, news & events, gallery and school content.

## 🛠️ Technologies Used

**Frontend:** HTML5, CSS3, JavaScript

**Backend:** Node.js, Express.js, REST API

**Database:** MongoDB, MongoDB Atlas

**Authentication:** JWT, bcryptjs, OTP Verification

**Email:** Nodemailer, Gmail SMTP

**Media Storage:** Cloudinary

**Deployment:** Render

## 🔐 Security

The system uses JWT-based authentication, password hashing with bcryptjs, email OTP verification and protected API routes to secure teacher and administrator operations.

## ☁️ Deployment

The website is deployed on Render and uses MongoDB Atlas for cloud database storage.

The website can operate independently without the developer's computer being online.

## 🔎 Google & SEO

The website has been connected with Google Search Console and includes:

* Google ownership verification
* XML Sitemap
* Search indexing
* Meta description
* Canonical URL
* Open Graph metadata
* Structured data

## 🎯 Project Goal

The goal of EduConnect is to provide Kadakati Arar High School with a modern, centralized and accessible digital platform for managing and presenting school information.
